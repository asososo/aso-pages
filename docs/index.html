好料（Ho-Liao）隱私政策

最後更新：2026 年 6 月 3 日  ｜  應用程式 ID：com.asoso.holiao

好料是一款完全在裝置本機運作的私房美食筆記應用。您的所有資料（餐廳清單、造訪紀錄、照片）均儲存於您的手機本機，不會上傳至任何遠端伺服器。

一、收集的資料

好料本身不收集任何個人識別資訊，也不設有帳號系統。以下資料由您主動輸入，僅存於您的裝置本機：

  • 餐廳／店家名稱、地址、評分、備註、標籤、營業時間
  • 造訪紀錄（日期、評分、心得）
  • 餐點名稱與備註
  • 您拍攝或選取的照片（複製至應用私有目錄，原始照片不受影響）

二、資料儲存方式

  • 結構化資料：使用 SQLite 資料庫儲存於裝置本機應用私有目錄，不與任何第三方共享。
  • 照片：儲存於應用私有目錄，系統相簿內容不受影響。
  • 設定偏好：透過 SharedPreferences 儲存於本機（主題模式、預設清單等）。

資料完全由您掌控，可透過應用內的「匯出」功能備份為 ZIP 檔案，或隨時透過解除安裝清除所有資料。

三、使用的第三方服務

Google Maps Platform（地圖與地點查詢）

好料使用 Google Maps API 提供以下功能：

  • 將 Google Maps 分享連結解析為地點名稱與地址（僅查詢 displayName、address、location）
  • 在應用內嵌入地圖，視覺化顯示已儲存的地點
  • 地圖導航（跳轉至 Google Maps 應用）

當您使用上述功能時，您的裝置會向 Google 發送請求。Google 的隱私政策適用於這些互動，請參閱：https://policies.google.com/privacy

四、應用程式權限

  • 位置權限：用於在地圖上顯示您目前的位置以便瀏覽附近已儲存的地點。位置資料不會儲存至資料庫，也不會傳送至任何伺服器。
  • 相機與相片庫權限：用於拍攝或選取照片，附加至造訪紀錄或餐點。照片僅複製至應用私有目錄。
  • 檔案存取權限：用於匯入 ZIP 備份檔案或將備份匯出至您指定的位置。

五、資料刪除

您可以隨時透過以下方式刪除資料：

  • 刪除單筆紀錄：在應用內直接刪除地點、造訪紀錄或餐點。
  • 清除全部資料：至裝置「設定 → 應用程式 → 好料 → 清除資料」，或直接解除安裝應用。

六、兒童隱私

好料不針對 13 歲以下兒童設計，也不刻意收集兒童的個人資訊。

七、隱私政策變更

若本政策有重大變更，將於此頁面更新日期並在應用商店版本說明中公告。建議您定期查閱本頁面。
