網址去漬機

貼上網址，展開短連結，去掉 utm、fbclid、gclid、igshid 這類追蹤參數。

參數清理完全在你的瀏覽器裡跑，不連外。只有短網址需要展開時才會呼叫代理。

在新分頁打開原連結，再把跳轉後的網址貼回來 ↗

代理錯誤細節

      參數規則涵蓋 utm_*、pk_*、mtm_* 等前綴，加上各平台專屬追蹤碼（YouTube 的 si、X 的 t/s、Threads 的 igshid/xmt、Bilibili 的 spm_id_from 等）。Amazon 商品頁會縮成 /dp/ 短形式，l.facebook.com 這類轉址包裝會自動拆掉。

      展開短網址老是失敗？用自己的端點

      填了就優先用它。端點收到網址後，回傳最終網址純文字或 {"url":"..."} 即可。這個檔案最下方的註解裡有一份可以直接貼上 Cloudflare Workers 的程式碼。網址只存在這個分頁，重整就沒了。
